# 空气污染是否会导致新生儿体重偏低？宝宝体重是否受到严重空气污染的影响？

> 更新时间：2026-09-18 (UTC+8)

由于经济的快速发展，我们的生活环境越来越差，空气质量也令人堪忧。严重的空气污染不仅影响成年人的健康，也危害下一代。欧洲近期一项大规模研究发现，怀孕期间生活在空气污染严重地区的更有可能生出体重较低的婴儿，而体重是新生儿健康的重要参考指标。

英国医学杂志《柳叶刀呼吸医学》15日在线发表的研究报告称，这项研究涉及欧洲12个国家的近7.5万名1994年至2011年间生育过的女性，由来自美国的人员组成的科研团队英国、法国、西班牙等国家对这些女性受访者的生活环境、怀孕时长、新生儿助孕和体重等进行了分析。

结果发现空气污染水平与低出生体重风险之间存在联系。如果每立方米空气中PM2.5颗粒浓度增加5微克，这种风险就会增加18%。研究还表明，居住在人口稠密地区的孕妇生下低出生体重婴儿的风险也更高。该研究将足月出生的婴儿定义为体重不足2.5 公斤。

研究人员表示，虽然这项研究结果不能将低出生体重直接归因于空气污染，但至少表明联系相当密切，从而再次证实了空气污染对人类健康的不利影响，因此特别值得关注。对控制空气污染具有重要意义。有必要限制可吸入颗粒物的排放。

新生儿出生体重过低是危险的

过去，人们普遍认为新生儿体重是否正常只会对其婴儿期和幼儿期产生一些影响。然而，国外学者经过多年的跟踪研究发现，其影响远不止于此。多年后回顾那些低出生体重的人，结果令人惊讶。

研究表明，出生时体重低于2500克、体长较短、头围较小的胎儿，尤其是孕妇体重低于45公斤的胎儿，长大后患心血管疾病的风险明显较高。 低出生体重者成年后发生糖耐量异常和2型糖尿病的风险增加，尤其是低出生体重者成年后肥胖。出生体重低的子代血压较高。体重每增加1000克，收缩压就会降低2.7毫米汞柱。 4. 出生体重低的人在青少年和成人时期患肥胖症的风险增加。这些人的整体肥胖水平可能不是很明显，但他们的腹部和躯干有明显的脂肪沉积。出生体重低且营养充足的个体更容易发生血脂异常。

低出生体重新生儿的护理需要更多护理

(1)喂养指南：必须强调母乳喂养。对于吸吮力较弱的孩子，可以将母乳挤入杯子中，用滴管喂养。逐渐增加喂食次数并观察体重增加情况。

(2) 绝缘指导

l) 定期测量体温，每小时或-6小时测量一次，并做好记录（正常每日体温应在36至37之间波动）。

2）室温保持在24~26。换尿布时，一定要先用热水袋加热尿布。

3）为新生儿保暖，可以使用热水袋或装满热水的密封瓶。将其放在两床被子之间，让宝宝的手脚保持温暖。

4）如果不满足上述条件，可以将孩子直接贴近大人身体保暖。

5）体重超过2000克的孩子，脐带脱落后可以每天洗澡。比较佳室温为28左右，洗澡水温为38-40。所有浴巾和衣服在使用前均应预热。

(三)护理指导

1）观察新生儿的吃奶、精力、面色、呼吸、哭闹、皮肤（注意黄疸、硬肿）以及大小便性质和次数，指导家长及时通知负责探视或前往的人员若发现异常，应及时到医院检查。

2）每次换尿布或做其他护理时，动作要轻柔、迅速，防止孩子着凉。

3）注意改变孩子的体位，定期翻身、侧卧。喂完奶后，应将孩子的头转向一侧，以免吐出奶汁吸入呼吸道。

4）注意脐部情况（按新生儿常规就诊处理）。

5）新生儿体重2周、28天各测量一次，但要注意保暖。对于全月体重增长低于600克的，应分析原因，给予指导，并将案件移入体弱婴项目病案管理。
